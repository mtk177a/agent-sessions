# Claude Code プロバイダー

> **注記:** [英語版](../claude.md) が正式版です。
> この日本語版は参考訳です。
> 内容に差異がある場合は英語版を優先します。

`claude` プロバイダーアダプターは、Claude Code を起動せずに、Claude Code の設定ルートから Claude Code のセッション記録を直接読み取る。

このアダプターは、以下の互換性境界をプロバイダーに依存しない安定した `v1` CLI 仕様へ対応付ける。\
トランスクリプトの JSONL 形式はアダプター内部のものであり、公開スキーマには含まれない。

## 検出の境界

Claude Code は `~/.claude` を既定の設定ディレクトリとして使用し、`CLAUDE_CONFIG_DIR` でそのディレクトリを上書きできる。\
主セッションのトランスクリプトは、そのルート下の `projects/<project>/<session-id>.jsonl` に保存される。

明示的な `--root` または設定されたソースルートは、プロジェクトディレクトリやトランスクリプトではなく、Claude Code の設定ルートを指定する。\
ソースの解決には、明示的なルート、設定されたソースインスタンス、`CLAUDE_CONFIG_DIR`、文書化された既定のルートの順序を共通して使用する。

アダプターは `projects` を決定的に走査する。\
プロバイダーのルートに含まれるサイズ制限内の通常ファイルだけを受け付け、シンボリックリンクと特殊ファイルを拒否し、内容を開くときにファイルとルートの同一性を再確認する。

プロバイダー固有のセッション識別子は、トランスクリプト内の検証済み `sessionId` フィールドから取得する。\
ファイル名は整合性の確認にだけ使用するため、トランスクリプトをプロジェクトの場所の間で移動しても `source_ref` は変わらない。

同じプロバイダー固有のセッション識別子を含む成果物が複数ある場合、アダプターはどのコピーが現在のものかを推測しない。\
`list` と `show` は曖昧さを報告し、内容に関する操作は `unsupported` を返す。

一覧のバージョンヒントは、成果物の数、サイズ、変更時刻をドメイン分離してハッシュ化したものである。\
検証では、共通の `VerifiedVersion` 仕様を通じてサイズ制限内の主トランスクリプトをハッシュし、パスを含まない証拠名 `transcript/primary.jsonl` を使用する。

## バージョン依存のデコード

デコーダーの対象は、Claude Code `2.1.177`、`2.1.228`、`2.1.260` について確認した内部トランスクリプト JSONL の構造である。\
Claude Code は各行の内部形式がリリース間で変わる可能性があると文書化しているため、異なる行のバージョンは推測で受け入れず、`complete` にはしない。

`2.1.228` との互換性は、公式の Claude Code 配布物と、文書化されたトランスクリプト、フック、ステータスライン、サブエージェントの場所に関する仕様に対して確認している。\
`2.1.177` との互換性は、プロバイダーが所有する非公開の記録に対して読み取り専用で確認し、独立して構築した合成フィクスチャでカバーしている。\
確認したのは構造上の性質だけであり、非公開の内容や識別子はこのリポジトリへコピーしていない。

`2.1.260` の行の書き出し構造は、署名済みの公式配布物を実行せず、実際のトランスクリプトをフィクスチャに使わずに調べた。\
すべての行の形式を確認したわけではなく、未知の行やブロックがある場合は `complete` にしない。

アダプターは、検証済みバージョンの `user`、`assistant`、`system`、`attachment` 行を受け付ける。\
公開するユーザーとアシスタントのテキスト、`tool_use` 呼び出し、明示的に相関付けられた `tool_result` ブロック、明示されたプロバイダー API エラーを正規化する。

既知の管理用行は公開観測ではなく、無視する。\
未知の行、未知の内容ブロック、添付ファイル、推論ブロック、内部ユーザーメタデータ、未対応のシステム観測は省略として報告する。

対応するユーザーとアシスタントのメッセージ行またはツール行の時刻のうち、最も遅いものを `last_interaction_at` とする。\
管理用の行、対応する非対話のシステム行、プロバイダー API エラーは、この時刻を進めない。\
時刻の欠落・不正値、やり取りの可能性がある未知の行やブロック、曖昧なトランスクリプトがある場合は、ソースの時刻を出さない。

ツール呼び出し ID は、セッション識別子とプロバイダーの相関識別子から決定的に生成する、アダプターが所有するハッシュである。\
結果は、明示された `tool_use_id` の値だけを通じて呼び出しと関連付ける。

重複した呼び出し、重複した結果、対応しない結果、保存された結果のない呼び出しがある場合、`complete` にはできない。\
結果の `success` 値は、検証済みの `tool_result.is_error` の意味だけから導出する。\
値がないか `false` なら成功、`true` なら失敗である。

公開するツールカテゴリは `shell`、`filesystem`、`file_change`、`mcp`、`tool` に限定する。\
既知のツール名を `execute`、`read`、`search`、`write`、`edit` に対応付け、それ以外の確認できた呼び出しは `invoke` とする。\
文字列とテキストブロックのツール結果には共通の安全な抜粋の規則を適用し、非テキストのブロックと安全でない行を除外して完全性を下げる。\
生のコマンド、ツール入力、無制限のツール出力、任意のプロバイダーツール名、プロバイダーの相関識別子、絶対パスは公開構造値として公開しない。

## サブエージェントとサイドカー

Claude Code は、サブエージェントのトランスクリプトを `projects/<project>/<session-id>/subagents/agent-<agent-id>.jsonl` に保存すると文書化している。\
現在の配布物は、これらの成果物に隣接するメタデータのサイドカーも書き出す。

アダプターは、直前に示したルート内のサブエージェント用パスだけを認識し、同じ通常ファイルとルート包含の検査を適用し、サイドカーのデコードにもサイズ制限を設ける。\
サイドカーの欠落、孤立、不正な形式、サイズ超過は明示的に報告する。

この互換性境界では、サブエージェントの成果物を独立した論理ソースとして公開しない。\
検証済みトランスクリプトとサイドカーの記録には、独立したプロバイダー固有のサブエージェント識別フィールドがなく、ファイル名からの識別やパスからの関係導出は共通の識別仕様に反する。

主ソースの検証証拠は主トランスクリプトだけである。\
そのため、サブエージェントのトランスクリプトとサイドカーが、主ソースの検証済み内容のバージョンを黙って変更することはない。

## 完全性と制限

安全に完全な形で表現できる観測は `complete` を返す。\
省略を伴う有用な観測は `partial` を返し、安全に有用な観測を一つも得られない認識済みソースは `unsupported` を返し、I/O、包含、置換競合、リソースの失敗は `error` を返す。

成果物は 64 MiB、識別子のプレフィックス、JSONL の行、サイドカーは 1 MiB、検出するファイルは 100,000 個、正規化するイベントは 100,000 件に制限する。\
これらは、公開レスポンスとページ分割の制限に加わるプロバイダー入力の制限である。

読み取り専用のコマンドは、インデックス、キャッシュ、ミラー、データベース、プロバイダーアプリケーションのメタデータ更新を作成しない。\
合成統合テストでは、代表的な `list`、`show`、`events`、`verify` 操作の前後で、プロバイダーのツリーに含まれるファイル集合、種類とモード、サイズ、変更時刻、内容ハッシュを比較する。

ホストのファイルシステムは、トランスクリプトファイルを読み取るとアクセス時刻のメタデータを更新する場合がある。\
ライフサイクルフック、ステータスライン統合、セッション再開、Agent SDK のアクセス、`/export`、`/insights`、同期、バックグラウンド取り込みは、検出や正しさの依存関係ではない。

## 公開されている場所の根拠

- [Sessions](https://code.claude.com/docs/en/sessions) には、トランスクリプトの保存と `projects/<project>/<session-id>.jsonl` の場所が記載されている。
- [Environment variables](https://code.claude.com/docs/en/env-vars) には、`CLAUDE_CONFIG_DIR` と既定の設定ディレクトリの動作が記載されている。
- [Hooks](https://code.claude.com/docs/en/hooks) には、ライフサイクル入力の `session_id` と `transcript_path` が記載されている。
- [Subagents](https://code.claude.com/docs/en/sub-agents) には、サブエージェントのトランスクリプトの場所が記載されている。

これらの参照先は、場所とライフサイクルの境界を示す。\
内部 JSONL エントリの形式を安定した公開 API にするものではない。
