# 日本語参考訳を保守する

> **注記:** [英語版](SKILL.md) が正式版です。
> この日本語版は参考訳です。
> 内容に差異がある場合は英語版を優先します。

## 目的と対象範囲

`docs/localization.md` に列挙された日本語参考訳を、対応する正式な英語版と整合させます。\
日本語参考訳は内容の理解とレビューに役立てるものであり、要件や権限を定めません。\
両者の内容が異なる場合は英語版を優先します。

この Skill が扱うのは、`docs/localization.md` に明記された 9 組だけです。\
Issue や Pull Request の執筆、ADR や一覧にないファイルの翻訳、翻訳保守の一環としての英語版の変更は行いません。
依頼が Issue または Pull Request の本文作成だけで、保守対象の英語版に変更がない場合は、この Skill の対象外であることを報告し、この作業では本文を作成しません。

## 手順

1. 依頼内容と現在の差分から、保守対象の組に含まれる、追加または変更された英語版を特定します。\
   変更箇所とその前後の文脈を読み、既存の日本語版があればそれも読みます。
2. 英語版の変更が、文書の正しい利用に必要な意味に影響するか判断します。\
   要件、対象範囲、例外、権限、禁止事項、安全上の条件、手順、検証、リンク、関連する構造は、意味に影響する場合があります。
3. 意味が変わった場合は、同じ変更内で対応する日本語参考訳を作成または更新します。\
   `must`、`should`、`may` の強さ、条件、例外、不確実さ、節同士の関係を保ちます。
4. 意味が変わらなかった場合は日本語版を変更せず、その理由を報告します。\
   Pull Request を準備する場合は、理由を「検証」または「リスク / フォローアップ」に記録します。
5. 対象となる各組について、意味の一致、既存の用語、英語版を正式版とする注記、正しい相対リンク、コードと識別子、Markdown の構造、意図しない変更を確認します。

各日本語参考訳には対応する英語版を示し、英語版が正式版であり、内容に差異がある場合は英語版を優先することを明記します。\
英語版の変更によって影響を受けた組だけを扱い、無関係な参考訳を書き直しません。\
英語版にない説明、例、規則、主張を追加しません。\
英語版の意味や既存の日本語の用語を確定できない場合は、推測せず、対象となる組と曖昧な点を報告します。\
独立した組の作業は可能な範囲で続けます。
一般的な訳語や音写を使っても、意味の異なる複数の解釈が残る場合は曖昧さを解消したことにはなりません。\
日本語の表現を中立に保てる場合も、判断に必要な文脈を報告します。

## 報告

対象となる各組の両方のファイルパスを示し、日本語参考訳を作成、更新、または変更不要とした結果と理由を報告します。\
実施した確認、解決していない曖昧さ、未確認の組も示します。

## 権限と依存関係

この Skill は、コミット、プッシュ、公開、権限変更、外部への送信を許可するものではありません。\
外部の翻訳サービス、依存追加、スクリプト、併用必須の Skill はありません。\
日本語の文章を扱う Skill も使う場合は、この Skill が意味と対象範囲を決めます。\
文章を扱う Skill は、その範囲内で表現を整えることができます。
