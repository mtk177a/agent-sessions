# 日本語参考訳を保守する

> **注記:** [英語版](SKILL.md) が正式版である。
> この日本語版は参考訳である。
> 内容が異なる場合は英語版を優先する。

## 対象範囲

[保守対象の一覧](../../../docs/localization.md#maintained-files) にある組だけを扱う。\
翻訳を保守する作業では、英語版を変更しない。

この作業で Issue や Pull Request の本文を作成しない。\
その作成だけを求められた場合は、この Skill の対象外だと報告する。

## 手順

### 1. 対象の組を選ぶ

依頼内容と差分から、一覧にある英語版のうち、追加・変更されたものだけを選ぶ。\
変更箇所と前後の文脈を読む。\
日本語参考訳がある場合は、それも読む。

### 2. 更新するか判断する

[言語方針で定める意味の範囲](../../../docs/localization.md#update-handling) に従い、対応を選ぶ。

| 判断結果 | 行うこと |
| --- | --- |
| 意味が変わる | 同じ変更内で日本語参考訳を作成・更新する。 |
| 意味が変わらない | 日本語版は変更せず、理由を報告する。Pull Request を準備するときは、Validation または Risks / Follow-up に理由を記録する。 |
| 英語版の意味や既存の訳語に、意味が大きく異なる解釈が残る | 推測せず、対象の組、曖昧な点、不足する文脈を報告する。可能なら、独立した組の作業を続ける。 |

意味が大きく異なる解釈が残る場合は、中立な訳語や音写を使えても、不足する文脈を報告する。

### 3. 必要な参考訳を書く

更新が必要な日本語参考訳だけを変更する。

- `must`、`should`、`may` の強さを保つ。
- 条件、例外、不確実さ、節同士の関係を保つ。
- 英語版にない説明、例、規則、主張を加えない。

### 4. 結果を確認する

- 日本語版の意味と既存の用語が、英語版と一致していることを確認する。
- [英語版を示す必須の注記](../../../docs/localization.md#required-reference-notice) があることを確認する。
- コード、識別子、相対リンク、Markdown、差分に意図しない変更がないか確認する。

### 5. 結果を報告する

対象となる各組について、次を報告する。

- 両方のファイルパス。
- 日本語版を作成・更新・据え置きのどれにしたかと、その理由。
- 実施した確認、解消していない曖昧さ、未確認の組。
