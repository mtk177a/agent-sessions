# Codex プロバイダー

> **注記:** [英語版](../codex.md) が正式版です。
> この日本語版は参考訳です。
> 内容に差異がある場合は英語版を優先します。

`codex` プロバイダーアダプターは、Codex App Server を起動せずに、Codex のホームディレクトリから Codex のロールアウト成果物を直接読み取る。

このアダプターは、以下の互換性境界をプロバイダーに依存しない安定した `v1` CLI 仕様へ対応付ける。\
ロールアウトの JSONL 形式はアダプター内部のものであり、公開スキーマには含まれない。

## 検出の境界

Codex は `$CODEX_HOME` をデータディレクトリとして文書化しており、この変数が設定されていない場合は `~/.codex` を使用する。\
セッションのトランスクリプトは `sessions` の下に保存され、アーカイブ済みトランスクリプトは `archived_sessions` の下に保存される。

明示的な `--root` または設定されたソースルートは、どちらか一方のトランスクリプト用サブディレクトリではなく、Codex のホームディレクトリを指定する。\
ソースの解決には、明示的なルート、設定されたソースインスタンス、`$CODEX_HOME`、文書化された既定のホームディレクトリの順序を共通して使用する。

アダプターは、両方のトランスクリプトの場所を決定的に走査する。\
プロバイダーのルートに含まれるサイズ制限内の通常ファイルだけを受け付け、シンボリックリンクと特殊ファイルを拒否し、内容を開くときにファイルとルートの同一性を再確認する。

検出では、サイズ制限内の最初の JSONL レコードだけを読み取る。\
`session_meta.payload.id` フィールドはプロバイダー固有のスレッド識別子なので、成果物をアクティブな場所とアーカイブ済みの場所の間で移動しても `source_ref` は変わらない。

同じスレッドを表す成果物が複数ある場合、アダプターはタイムスタンプとロールアウト ID による Codex の現在のロールアウト選択順序に従う。\
その順序で現在の成果物を区別できない場合、内容に関する操作はコピーを黙って一つ選ばず `unsupported` を返す。

一覧のバージョンヒントは、ファイルサイズと変更時刻をドメイン分離してハッシュ化したものである。\
検証では、共通の `VerifiedVersion` 仕様を通じてプロバイダーの内容をサイズ制限内でハッシュし、パスを含まない証拠名 `rollout/primary.jsonl` を使用する。

## バージョン依存のデコード

デコーダーの対象は、Codex CLI `0.149.1` が書き出したロールアウト JSONL に限定している。\
互換性は、公式の `openai/codex` タグ [`rust-v0.149.1`](https://github.com/openai/codex/tree/rust-v0.149.1) のコミット [`ff29a44391deccde0aba0f8390337d7f3c319ea4`](https://github.com/openai/codex/commit/ff29a44391deccde0aba0f8390337d7f3c319ea4) に対して、プロトコル、履歴、スレッドストア、状態抽出の実装を含めて確認している。

アダプターは、公開される観測に必要な `session_meta`、`event_msg`、`response_item` のロールアウト用エンベロープを認識する。\
旧形式の履歴では、`user_message` と `agent_message` のイベントが正規のメッセージ行であり、レスポンスのツール呼び出しと保存済みの出力行が相関の証拠を提供する。\
旧形式の出力行には内部の成功値が保存されないため、アダプターは結果を推測せず、正規化した結果を省略する。\
ページ分割された履歴では、完了済みの `UserMessage`、`AgentMessage`、`CommandExecution`、`McpToolCall`、`DynamicToolCall` の項目が正規のものとなり、下位レベルのレスポンス行は重ねて出力しない。

ツール呼び出し ID は、スレッド識別子とプロバイダーの相関識別子から決定的に生成する、アダプターが所有するハッシュである。\
公開するカテゴリは `shell`、`file_change`、`mcp`、`tool` に限定し、生のコマンド、引数、ツールのペイロード、任意のプロバイダーツール名は公開構造フィールドへ正規化しない。

エラーは、明示されたプロバイダーのエラーイベントから正規化する。\
親子関係とフォーク関係は、明示された `parent_thread_id` と `forked_from_id` のメタデータからのみ出力する。

## 完全性と制限

不明なエンベロープ、不明なイベント種別、既知だが未対応の項目またはメッセージ内容、不正な JSONL、サイズ超過した行、相関情報やツール結果の欠落、重複した呼び出し ID、不正な関係識別子、未検証の CLI バージョンがある場合、`complete` にはできない。\
有用な観測がある場合は `partial` を返し、認識したソースから安全で有用な結果を得られない場合は `unsupported` を返し、I/O とリソースの失敗は `error` を返す。

圧縮された `.jsonl.zst` ロールアウトは認識するが、実行ファイルに外部圧縮依存がないためデコードしない。\
`history_base` を持つロールアウトでは、現在の成果物の観測だけを返し、継承された先頭部分を省略したことを `partial` として明示する。

成果物は 64 MiB、個々の行とヘッダーは 1 MiB、検出するファイルは 100,000 個、正規化するイベントは 100,000 件に制限する。\
これらは、公開レスポンスとページ分割の制限に加わるアダプター入力の制限である。

読み取り専用のコマンドは、インデックス、キャッシュ、ミラー、データベース、プロバイダーアプリケーションのメタデータ更新を作成しない。\
ロールアウトファイルを読み取ると、ホストのファイルシステムがアクセス時刻のメタデータを更新する場合がある。\
ライフサイクルフック、事前登録、同期、バックグラウンド取り込みは、検出の依存関係ではない。

## 公開されている場所の根拠

OpenAI の [Codex トラブルシューティング文書](https://learn.chatgpt.com/ja-JP/docs/reference/troubleshooting) には、Codex のホームディレクトリ、アクティブなセッションのトランスクリプトの場所、アーカイブ済みセッションのトランスクリプトの場所が記載されている。\
JSONL の行のデコードは、保存された行が安定した公開 API であるという主張ではなく、アダプターが所有する互換性境界である。
